# Soxoa Ops

Fifteen portable operating skills for feedback, signup visibility, work briefs, clear handoffs, marketing, writing, research and automation scoping.

This package contains instructions and an icon. It has no MCP configuration, credentials, hooks, executables or background workers. Skills use the host’s available authorized sources and tools, and return a supported partial result or setup handoff when a dependency is missing. Installing instructions does not connect an account or grant permission for paid work, messages or deployment.

See the [dated distribution status](../../DISTRIBUTION_STATUS.md). Both the portable root manifest and Codex/Claude compatibility manifests are included. The `skills/` directory contains the complete instructions; there are no private repository dependencies.

Use a compatible host’s documented local-plugin or skills-only ZIP import flow. Complete listing review and clean-environment testing before any public submission. No account setup is performed automatically.

## Workflows

- `soxoa-ops-ad-path-check`: Prepare evidence-based ad concepts and audit their landing, signup and test-checkout paths before a proposed campaign.
- `soxoa-ops-audit-site-discoverability`: Audit an authorized website’s page inventory and internal links for disconnected content and crawl barriers.
- `soxoa-ops-build-editorial-pitch-pack`: Prepare sourced articles and outlet-specific editorial pitches with current submission rules and exclusivity tracking.
- `soxoa-ops-build-marketing-kit`: Build coordinated marketing assets from dated product facts, brand assets and approved evidence.
- `soxoa-ops-build-voice-guide`: Build a reusable writing voice guide from authorized samples with channel-specific rules and provenance.
- `soxoa-ops-chief-of-staff-brief`: Summarize a stated work period from authorized activity records, distinguishing changed, verified and released work.
- `soxoa-ops-claim-audit`: Review supplied or authorized marketing copy for clear positioning, unsupported claims and evidence-based replacements.
- `soxoa-ops-evaluate-ai-output`: Review an existing AI result against source evidence and prospective acceptance criteria, preserving errors and unresolved scope.
- `soxoa-ops-feedback-inbox`: Capture user-supplied customer feedback verbatim, group it into issues and rank distinct requesters without choosing what gets built.
- `soxoa-ops-owner-actions`: Prepare a requested action handoff separating verified results, remaining authorized agent work and decisions needing a person.
- `soxoa-ops-research-prospect-brief`: Prepare a sourced business prospect brief with alternative explanations, rejection rules and an unsent draft when requested.
- `soxoa-ops-scope-automation-opportunity`: Scope a recurring workflow into automate, assist, discovery or stop with review gates and illustrative economics.
- `soxoa-ops-screenshot-moment`: Review an authorized product flow to identify a truthful result customers might share and rank practical sharing improvements.
- `soxoa-ops-signup-pulse`: Review signup progress or implement requested owner alerts and digests using authorized product data and reliable delivery recovery.
- `soxoa-ops-write-evidence-article`: Write and revise a practical article from retained evidence with separate factual and style review.

The handoff skill applies when a handoff is requested. Signup alerts, storage updates, external submissions and recurring work occur only within the actual user request and supported tools. Drafting and static validation do not prove an email was delivered, a campaign was launched or an automation was installed.
