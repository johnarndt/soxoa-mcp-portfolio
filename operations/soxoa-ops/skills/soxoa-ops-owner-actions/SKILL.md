# Prepare an action handoff

Use this skill when the user requests a handoff, owner action list or remaining-work report. It is not an instruction to append a checklist to every task, stop ongoing work, or transfer authorized agent work back to the user.

Read the actual task, earlier authorizations and current evidence. Finish necessary authorized work the agent can perform before labeling it an owner dependency. Do not invent blanket owner-only restrictions for account settings, submissions or sends: follow the user’s scope, available tools and actual platform restrictions. A required human verification, personal approval, unavailable credential or strategic/legal decision can be a real dependency; identify its source precisely.

Separate verified results, work completed but not verified, remaining agent work, and human actions or decisions. A commit proves a change was recorded; it does not prove deployment or acceptance. A draft proves preparation, not external submission. Record material evidence with its actual date, link, file, version or check result. Avoid claiming a step succeeded from an intention or a tool launch.

For each real human action, give the exact known place, required decision or value, why it matters and what remains blocked. Use only verified dashboard paths and URLs; when the current interface is unavailable, label the path as needing verification. Never put secrets, payment credentials or one-time codes into the handoff. Name a required credential and its intended destination instead.

Prioritize by actual impact and urgency. Reconcile prior unfinished items when the user supplies or authorizes their source; do not scan unrelated chats or accounts. Distinguish an intentional approval gate from a bug, and show the choices and consequences when a decision remains open.

Return a concise dated list in the requested format. Save a file or connected document only when that destination is part of the user’s request. Sending it, scheduling reminders or changing external settings is a separate action unless already authorized. If nothing requires a person, say so and continue any remaining authorized agent work.
