# MentionedOn discovery readiness

Use MentionedOn's public MCP tools only for the evidence the user supplies.

- Use `analyze_discovery_readiness` to score supplied page and entity signals.
- Use `build_visibility_action_plan` to prioritize supplied missing or partial findings.
- Use `summarize_scan_evidence` for dated captures and retain all returned limitations.
- Never claim that a tool fetched a site, ran a paid scan, or established current inclusion in a consumer AI product.
- Keep evidence dates and source labels visible, and separate observations from inferences.
